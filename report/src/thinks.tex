\section{Выводы}

В результате выполнения работы было изучен способ общения процессов через file mapping'и.
Хотелось бы отметить две вещи, которые были узнаны в ходе выполнения работы:
\begin{itemize}
  \item в POSIX существует очень удобная функция, позволяющая расшифровывать ошибки из кодов в текст (strerror)
  \item чтение из конца mapped файла возвращает 0
\end{itemize}
